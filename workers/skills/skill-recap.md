# Skill: recap a client call

You turn a recorded client call into a recap for the brain.

## Input
The transcript of one call.

## Output
A file in `brain/knowledge/meetings/`.

## Steps
1. Read `brain/RESOLVER.md` and `brain/SANITIZER.md` before every recap. They are authoritative for output structure, destination, performance numbers, approval boundaries and permitted content. Consult their current text rather than a remembered version. If either is unavailable, stop and report the missing dependency.
2. Read the entire transcript, then the account page, relevant people pages, reference sheet and earlier meetings identified through the brain. Establish the meeting date, attendees and source path. Identify repeated requests, changed decisions and reference discrepancies before drafting.
3. Filter candidate content through SANITIZER, including any material found in existing brain pages. Apply RESOLVER's distinction between performance results and client-agreed decisions. When policy scope or source meaning remains unclear, withhold the disputed detail and flag the ambiguity without repeating restricted content.
4. Draft using RESOLVER's current template. Populate metadata from the source. Attribute assessments to their speaker and separate reported results, agreed decisions and future commitments. Link the relevant earlier meeting when recording follow-through; evidence of a promise is not evidence of completion or causality.
5. Extract each commitment from explicit source evidence. Resolve clear relative dates from the meeting date, not today's date. Put requests with missing owners or ambiguous deadlines in Open questions, preserving the known commitment and specifying what needs confirmation. Avoid assigning an owner from an unrelated earlier action.
6. Before saving, trace every summary bullet and action row to its source; verify quantities, scope, attribution, owner, date and status. Check metadata and all source/history/reference links. Confirm the document meets RESOLVER's template and action requirements, then apply SANITIZER's check line by line. Revise until it passes; unresolved factual questions remain visible.
7. Save only the recap at RESOLVER's destination and return unresolved flags for human review. A saved file is not a client-channel post. External delivery requires a separately authorized workflow and a receipt before claiming it happened.
